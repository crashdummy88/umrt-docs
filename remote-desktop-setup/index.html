Remote session setup

Remote desktop setup for your remote session

Do this on the coach laptop before your session.

Call (616) 606-5277 Text Now

What we need and why

We need a laptop on your coach network and online, so we can pull your GX settings file and tune your network. That means:

  • Connected to your coach network (Peplink, GL.iNet, cell modem or whatever you run) and to the internet.
  • At the coach and powered on for the session.
  • Google Chrome installed.

For a one-off session on a computer, we use United Mobile RV Connect or Chrome Remote Desktop. We’ll text you which one we’ll use for your session.

Macs: we use FaceTime or Zoom for now. Mac, Raspberry Pi, and Android are supported only after testing with us.

On your computer, nothing happens until you click Allow, and you can end the session any time. For remote-access boxes on Managed and Fleet plans, which can’t show a prompt, we text you before every session and wait for your reply.

Text “pause” and we pause our access within 4 hours during the day, or the same evening if you text late. While paused, your computer still asks before anything happens, and a remote-access box can’t be reached at all. Text “resume” to turn access back on.

If we text you a United Mobile RV Connect link, open it on the Windows computer. Only run an install link we texted you. If Chrome says This file isn’t commonly downloaded and it may be dangerous, click Download suspicious file. If it says Keep, choose Keep. When you open the file, Windows shows a blue box: Windows protected your PC. Click More info, then Run anyway. When Windows asks to allow changes, click Yes. In the Connect installer, click Install only. To remove it later, find Mesh Agent in your apps list. How we connect shows which tool we use for a phone, a Peplink router, or a Victron system.

TeamViewer: only if we ask.

1. Chrome Remote Desktop (one-time code)

This is the only Chrome Remote Desktop path. You stay at the laptop, and we only get in while you’re sharing. You need a free Google account to get the one-time code. Gmail works. The first time, it installs a small helper. We never ask for a PIN or password.

  1. Open Chrome and go to remotedesktop.google.com/support.
  2. Click Share this screen.
  3. Read us the code. It only works once.
  4. Click Stop Sharing anytime to end it. On long sessions Chrome asks you every 30 minutes to keep sharing.

TeamViewer: only if we ask

TeamViewer: only if we ask. If we use it, we’ll text you first. You read us the ID and the one-time session code shown in your TeamViewer window. That code changes every session. We never ask for your computer, email or account passwords.
