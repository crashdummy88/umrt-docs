Remote session setup

Remote desktop setup for your remote session

Do this on the coach laptop before your session.

Call (616) 606-5277 Text Now

What we need and why

We need a laptop on your coach network and online, so we can pull your GX settings file and tune your network. That means:

  • Connected to your coach network (Peplink, GL.iNet, cell modem or whatever you run) and to the internet.
  • At the coach and powered on for the session.
  • Google Chrome installed.

For a one-off session on a computer, we use United Mobile RV Connect or Chrome Remote Desktop. We’ll text you which one we’ll use for your session.

Macs use FaceTime or Zoom screen share until Mac testing is done.

We text before every session. If you text PAUSE, we stop within 4 hours during the day, or the same evening.

If we sent you a United Mobile RV Connect link, follow the Connect install guide. How we connect shows which tool we use for a phone, a Peplink router, or a Victron system.

TeamViewer is a backup option. We’ll only use it if we ask.

1. Chrome Remote Desktop

When we text you to use Chrome Remote Desktop, you stay at the computer and read us a one-time code. You need a free Google account to get that code. Gmail works. The first time, it installs a small helper. You never share a PIN.

  1. Open Chrome and go to remotedesktop.google.com/support.
  2. Click Share this screen.
  3. Read us the code. It only works once.
  4. Click Stop Sharing anytime to end it.

2. TeamViewer QuickSupport (backup)

TeamViewer is a backup option. We’ll only use it if we ask.

  1. Open the official TeamViewer QuickSupport download page, download QuickSupport, and run it.
  2. Read us the one-time session code shown in TeamViewer. We only ask for a one-time session code, never your passwords.
  3. When the request appears, click Allow access.
