Remote support

How we connect

We use a few tools. The right one depends on the device.

Pick the device

There isn’t one app for every piece of gear in a rig. We match the tool to what we’re looking at.

  • United Mobile RV Connect for a Windows computer. Mac, Raspberry Pi, Linux, and Android are after testing.
  • Chrome Remote Desktop for a computer, when we text you to use it
  • TeamViewer is a backup option. We’ll only use it if we ask.
  • Zoom or FaceTime for a phone, a tablet, or a camera walk-through
  • Peplink InControl2 for a Peplink router
  • VRM (Victron’s free monitoring site) for a Victron system on a Cerbo GX or other GX device
  • SSH for an OpenWrt or GL.iNet router, only with your OK

For a one-off session on a computer, we use United Mobile RV Connect or Chrome Remote Desktop. We’ll text you which one we’ll use for your session.

Packages are listed at unitedmobilerv.com/remote.

1. United Mobile RV Connect

United Mobile RV Connect is our remote-support app. Right now we install it on Windows PCs and laptops. Mac, Raspberry Pi, Linux, and Android are after testing.

We text or email you a private install link. It works for 7 days. You open it on the Windows computer we’ll support. You don’t log in. Each time we connect, you click Allow. Nothing happens until you do. A toolbar stays on screen while we’re connected, and you can disconnect anytime. If we used Connect only for that session, we remove the app afterward. On a monitoring plan, it stays installed.

On Windows, the installer shows a warning. That warning stays. The file comes straight from our server for your rig, and it isn’t sold in a store, so Windows doesn’t recognize it. Only run it if we sent the link. Call or text (616) 606-5277 if you want to check first. If Windows won’t show Run anyway (Smart App Control, S mode, or a work laptop): Text us and we’ll use Chrome Remote Desktop instead. United Mobile RV LLC is a licensed business and an Authorized Victron Energy Dealer. You approve every session. Every Connect session is logged. You can see us working and disconnect anytime, and you can remove access whenever you want. The full note is in why Windows shows a warning.

Steps and pictures: Install United Mobile RV Connect.

2. Chrome Remote Desktop

When we text you to use Chrome Remote Desktop, you stay at the computer. You need a free Google account to get the one-time code. Gmail works. The first time, it installs a small helper. Open the support page, click Share this screen, and read us the code. The code only works once. You can stop sharing anytime. You never share a PIN.

Steps: Remote desktop setup, including the one-time code.

3. TeamViewer

TeamViewer is a backup option. We’ll only use it if we ask. You read us the one-time session code shown in TeamViewer. The short steps are on the remote desktop page.

4. Zoom or FaceTime screen share

For a phone, tablet, or Chromebook today, we use Zoom or FaceTime screen share. That includes an iPhone or iPad. Android in United Mobile RV Connect is after testing.

The same call works when we need to see a panel, a breaker, or a screen in the rig. You point the camera, and we walk through it together.

5. Peplink InControl2

Peplink routers are cloud-managed. You grant us access to your device in InControl2. We don’t take the router off your account unless you ask us to. You can remove that access whenever you want.

6. VRM

For a Victron system on a Cerbo GX or other GX device, you share access with us on VRM. From there we can view the system and open the remote console. You stay the admin of your installation, and you can remove us whenever you want.

7. SSH for OpenWrt and GL.iNet

Some OpenWrt and GL.iNet routers are easier to check from a secure command line. We only do that with your permission, during a session you asked for. We don’t keep a way in after you tell us to stop.

Your OK comes first

We only connect when you ask, or when you approve it. Every Connect session is logged. You can revoke access anytime: disconnect, uninstall, or tell us to remove our access and we’ll do it.

We text before every session. If you text PAUSE, we stop within 4 hours during the day, or the same evening.

We only ask for a one-time session code, never your passwords.
