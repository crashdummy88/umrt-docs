What this app is

United Mobile RV Connect (UMRV Connect) is a small app that lets us reach one computer in your rig when you want help. We use it to look at settings and fix power, solar, and internet gear without a trip out. It’s built on MeshCentral, an open-source remote tool, and we run it on our own server at connect.unitedmobilerv.com.

We never connect without asking. See how we connect for the other tools we use, including phones and routers.

1. Open the link we sent you

We text or email you a private install link. It works for 7 days. Open it on the computer we’ll support:

  • A Windows PC or laptop
  • A Mac
  • A Raspberry Pi or other Linux computer

Don’t share the link. If it has expired, or you didn’t expect it, call or text (616) 606-5277 before you download anything. Only run the installer if the link came from us.

The page looks like this. Pick your system, then choose Download the software here.

On a phone browser, the same page stacks like this. Still open the link on the computer we’ll support, not on the phone, unless we asked you to.

2. Windows

Download the small installer and run it. The file name starts with meshagent64. Yours may also have a short code after that. That’s normal. The install window may say MeshCentral Agent. That’s the tool underneath United Mobile RV Connect.

You’ll see a warning. Here’s why. The file comes from our own server, and it’s built for your link, so Chrome and Windows haven’t seen that exact file before. We also haven’t signed it with a paid Microsoft certificate yet. That’s why Windows lists the publisher as unknown. It is still our installer.

  1. Chrome may say This file isn’t commonly downloaded and it may be dangerous. Click Download suspicious file. If your browser says Keep instead, choose Keep.

  2. When you open the file, Windows shows a blue box: Windows protected your PC. Click More info.

  3. Check that the app name starts with meshagent64. The publisher will say Unknown publisher. Then click Run anyway.

  4. If Windows asks to allow changes, choose Yes.
  5. In the install window, choose Install if we’re leaving it on the computer for ongoing help, or Connect for a one-time session. If you’re not sure which button, text us and we’ll tell you.
  6. Text us “installed” so we can confirm we see it.

Only do this if the link came from us by text or email. Our number is (616) 606-5277. If the buttons look different, or there is no Run anyway button, stop and call us. We’ll sort it out together.

3. Mac

  1. Open the link on the Mac and download United Mobile RV Connect.
  2. Open the download and follow the prompts. The Mac version isn’t signed by Apple yet, so macOS may say it can’t check the app. Don’t choose Move to Trash. Call or text us and we’ll walk through the next click with you.
  3. The first time, macOS asks you to allow Screen Recording and Accessibility for the app. That’s in System Settings, under Privacy & Security. We’ll walk you through it on the phone.
  4. Text us “installed”.

4. Raspberry Pi or Linux

Open the same link on that computer and choose the Linux download. Stay on the phone with us while it installs. A Pi often has no screen prompt, so your OK is the one you already gave us when you asked us to set it up.

5. When we connect

  • Every time we connect, you get an Allow / Deny prompt. Nothing happens until you click Allow.
  • While we’re connected, a toolbar stays on the screen. You can disconnect anytime.
  • We never connect without asking.
  • After a one-time session, we remove the app.
  • If you’re on a monitoring plan, the app stays installed so we can help the next time you ask. You still get the Allow prompt.

6. Remove it later

You can take United Mobile RV Connect off the computer whenever you want.

  • Windows: open Settings, then Apps, then Installed apps. On some computers that page is named Apps & features. Find United Mobile RV Connect and choose Uninstall. If the name looks a little different, text us and we’ll point to the right row.
  • Mac: text us and we’ll remove it with you.
  • Raspberry Pi or Linux: text us and we’ll send the removal steps for that computer.

Removing the app doesn’t cancel a plan by itself. Text us if you also want the plan to stop.

7. Phones, tablets, and Chromebooks

United Mobile RV Connect does not cover these:

  • iPhone or iPad
  • Chromebooks
  • Android phones (limited)

For those, we use Zoom or FaceTime screen share. We can also point the camera at a panel and walk through it together. That’s covered on how we connect.
