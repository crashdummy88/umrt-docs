What this app is

United Mobile RV Connect (UMRV Connect) is a small app that lets us reach one Windows computer in your rig when you want help. We use it to look at settings and fix power, solar, and internet gear without a trip out. We run it on our own server. You don’t log in.

For a one-off session on a computer, we use United Mobile RV Connect or Chrome Remote Desktop. We’ll text you which one we’ll use for your session.

We never connect without asking. See how we connect for the other tools we use, including phones and routers.

We text or email you a private install link. It works for 7 days. Open it on the Windows computer we’ll support.

Mac, Raspberry Pi, Linux, and Android are after testing. We don’t have install steps for those yet.

Don’t share the link. If it has expired, or you didn’t expect it, call or text (616) 606-5277 before you download anything.

2. Windows

Download the small installer and run it. The file name starts with meshagent. Yours may also have a short code after that. That’s normal. The app is United Mobile RV Connect.

Why Windows shows a warning, and why it’s safe

Windows will pause and ask if you’re sure. That warning stays. It shows up every time someone installs this file.

The installer comes straight from our own server, and it’s made for your rig only. It isn’t sold in a store, so Windows doesn’t recognize it and lists the publisher as unknown. The file name still starts with meshagent.

Only run it if the link came from us. If you’re not sure, call or text (616) 606-5277.

United Mobile RV LLC is a real licensed business and an Authorized Victron Energy Dealer. With your OK, we connect to the devices and networks on your rig and fix the problem with you. You approve every session. Every Connect session is logged. You can see us working, and you can disconnect anytime. You can remove access whenever you want. That’s how we sort it out without a service call or waiting on a shop.

Here’s what to click.

  1. Chrome may say This file isn’t commonly downloaded and it may be dangerous. Click Download suspicious file. If your browser says Keep instead, choose Keep.

  2. When you open the file, Windows shows a blue box: Windows protected your PC. Click More info.

  3. Check that the file name starts with meshagent. The publisher will say Unknown publisher. Then click Run anyway.

  4. When Windows asks to allow changes, click Yes.
  5. In the install window, click Install.
  6. Text us “installed” so we can confirm we see it.

If Windows won’t show Run anyway (Smart App Control, S mode, or a work laptop): Text us and we’ll use Chrome Remote Desktop instead.

3. Other devices

Windows is the install we do now.

After testing: Mac, Raspberry Pi, Linux, and Android. We’ll tell you when those are ready.

For an iPhone, iPad, or Chromebook, we use Zoom or FaceTime screen share. We can also point the camera at a panel and walk through it together. That’s covered on how we connect.

4. When we connect

  • Every time we connect, you get an Allow / Deny prompt. Nothing happens until you click Allow.
  • While we’re connected, a toolbar stays on the screen. You can disconnect anytime.
  • We never connect without asking.
  • We text before every session. If you text PAUSE, we stop within 4 hours during the day, or the same evening.
  • We only ask for a one-time session code, never your passwords.
  • If we used Connect only for that session, we remove the app afterward.
  • If you’re on a monitoring plan, the app stays installed so we can help the next time you ask. You still get the Allow prompt.

5. Remove it later

You can take United Mobile RV Connect off the computer whenever you want.

Open Settings, then Apps, then Installed apps. Find Mesh Agent and click Uninstall. Or text us and we’ll remove it for you.

Removing the app doesn’t cancel a plan by itself. Text us if you also want the plan to stop.
